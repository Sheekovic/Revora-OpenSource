# Revora Launcher 1.0.7

## English

1. Extract the complete ZIP into a new writable folder owned by your Windows user. Do not run the launcher from inside the ZIP and do not install it under `Program Files`.
2. Run `Revora.Launcher.exe` normally; administrator rights are not required.
3. The launcher downloads, verifies, repairs and updates only files covered by Revora's signed client manifest.
4. Close any running Revora/Conquer game before a repair or update. The launcher never terminates the game automatically.
5. When verification succeeds, the launcher starts the genuine game client. Enter your account username and password inside the game.

The launcher preserves unmanaged screenshots, settings and logs. Do not download loose `Conquer.exe` files from third-party sources.

## العربية

1. فك ضغط ملف ZIP كاملًا داخل مجلد جديد قابل للكتابة يملكه مستخدم Windows. لا تشغّل اللانشر من داخل ملف ZIP ولا تثبّته داخل `Program Files`.
2. شغّل `Revora.Launcher.exe` بشكل عادي؛ لا تحتاج إلى صلاحيات المسؤول.
3. يقوم اللانشر بتنزيل ملفات عميل ريفورا والتحقق منها وإصلاحها وتحديثها وفق بيان ملفات موقّع.
4. أغلق لعبة Revora/Conquer إذا كانت تعمل قبل الإصلاح أو التحديث. لن يقوم اللانشر بإغلاق اللعبة تلقائيًا.
5. بعد اكتمال التحقق، يشغّل اللانشر عميل اللعبة الأصلي. أدخل اسم المستخدم وكلمة المرور داخل اللعبة.

يحافظ اللانشر على لقطات الشاشة والإعدادات والسجلات غير المُدارة. لا تحمّل ملفات `Conquer.exe` منفردة من مصادر خارجية.
