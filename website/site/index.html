Before your journey

A few things to know.

A clear starting point, whether you're exploring the project or building your own realm.

Is Revora really free?

Yes. Revora-authored source is released under the MIT license. Third-party libraries retain their own terms. Stars, follows, and voluntary donations help support the work.

Does the website need ASP.NET?

No. This website is plain HTML, CSS, and JavaScript. Open index.html, use a static server, or publish the site folder to GitHub Pages. Account services use a separately configured backend.

Can I play from this preview?

This is the public website preview. No game server or account service is connected here. Operators need a reviewed 6711 runtime, game data, and a compatible client setup.

Where do I start with the server?

Download the repository and read QUICKSTART.md. The setup entry point checks prerequisites and prepares local services. Missing legacy assemblies and private runtime data must be supplied lawfully.
